Workflow

How CommentInsight Works

CommentInsight follows a simple step-by-step workflow from comment input to sentiment results, saved history, and CSV export.

01

Enter Comments

Users enter up to 5 social media comments into the analysis form.

02

Select Models

SVM is used as the primary model. Logistic Regression and Naive Bayes can be selected optionally for comparison.

03

Analyze Comments

The system processes the comments using the selected machine learning models and generates sentiment predictions.

04

View Results

Users can review sentiment labels, charts, per-comment predictions, and extra sentiment scores.

05

Save / Download History

Analysis results are saved into history. Users can download one record as CSV or export selected records into one combined CSV file.

About CommentInsight

Built for Faster and More Consistent Sentiment Analysis

CommentInsight is a web-based sentiment analysis system designed to reduce the time and effort required for manual sentiment analysis. Manual sentiment analysis can be time-consuming, especially when dealing with large volumes of social media comments.

In addition, human judgement may become less consistent over time due to fatigue and subjective interpretation. To address these issues, CommentInsight uses machine learning techniques to classify comments into positive, neutral, and negative sentiment more efficiently.

The system uses SVM as the primary model and allows Logistic Regression and Naive Bayes to be selected optionally for comparison. It also supports extra sentiment scores, analysis history, and CSV export.
